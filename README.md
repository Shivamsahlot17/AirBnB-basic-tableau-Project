# 🏠 Airbnb Data Analysis Dashboard (Tableau)

## 🔍 Project Overview

This project analyzes Airbnb listing data using Tableau to uncover insights about pricing trends, availability, locations, and customer preferences. The dashboard helps understand how different factors influence listing performance.

## 🛠 Tools Used

* Tableau
* Excel / CSV

## 📂 Dataset

The dataset contains information about Airbnb listings, including:

* Price
* Location (neighbourhood/area)
* Room type
* Availability
* Number of reviews
* zipcode
* listing_id
* country
* state
* calender
  And many more

## 📈 Key Insights

* Entire homes/apartments have higher average prices compared to private rooms
* Certain locations/neighbourhoods show significantly higher demand
* Listings with more reviews tend to have better occupancy trends
* Price distribution varies widely across room types and areas

## 📊 Dashboard Features

* Interactive filters (location, room type, price range)
* Price comparison across different neighbourhoods
* Availability and listing distribution analysis
* Clean and intuitive visual design
